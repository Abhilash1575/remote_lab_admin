CSV file format

Your CSV file should contain the following columns (header row required):

  • Name - Full name of the user (required)
  • Email - Email address (required, must be unique)
  • Phone Number - Contact number (optional)
  • SR Number - Student/Employee registration number (optional)
  • Course ID - Course identifier (optional)
  • Course Name - Name of the course (optional)
  • Department Name - Department name or code (optional)
  • Company/College Name - Organization name (optional)
